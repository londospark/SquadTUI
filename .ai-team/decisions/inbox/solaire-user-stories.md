# User Stories — Solaire (Lead)

> Sprint 17 · Feature: Navigation Revamp

### 1. Architecture Observability

As a **Lead**, I want to see a tree view of the squad's file structure (agents, charters, decisions, history) so that I can verify the project is properly organized without leaving the TUI.

### 2. Decision Search and Filtering

As a **Lead**, I want to search and filter decisions by author, date range, or keyword so that I can quickly find prior architectural rulings during code review without manually scanning the decisions file.

### 3. Sprint Velocity Comparison

As a **Lead**, I want to see a side-by-side comparison of the current sprint's velocity against the previous two sprints so that I can identify slowdowns early and adjust scope before the sprint ends.

### 4. Code Review Queue

As a **Lead**, I want a dedicated screen showing open PRs, their CI status, and which squad member owns each so that I can triage reviews and unblock the team without context-switching to GitHub.

### 5. Decision Drafting from TUI

As a **Lead**, I want to draft and save a new decision entry directly from the TUI (title, rationale, consequences) so that architectural decisions are captured in the moment rather than deferred and forgotten.
